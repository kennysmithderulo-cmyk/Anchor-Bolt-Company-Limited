# Project context — Anchor-Bolt Company Limited website

## What this is
Premium corporate marketing website for Anchor-Bolt Company Limited, a construction and real-estate development company at 12 Sanderling Street, Airport Ridge, Sekondi-Takoradi, Western Region, Ghana. Phone +233 244 57 96 89. Public site — no login/auth (by design; the client asked for a business website with a consultation enquiry form).

## Stack and integration status (COMPLETE)
- Frontend: React + Vite + TS, React Router, React Query, shadcn/ui, lucide-react. All data comes from the FastAPI backend via `API_URL` (`frontend/src/lib/api.ts`). No mock or hardcoded content data.
- Backend: `backend/server.py` — FastAPI + MongoDB (Motor). Product routes under `/api`, seeded once on startup. Consultation submissions persist to the `consultations` collection.
- Contract: see `contracts.md`. Design: see `design_guidelines.md` (locked palette + fonts in `frontend/src/index.css`).

## Routes (frontend)
`/` Home · `/about` About · `/services` Services · `/our-work` Our Work · `/process` Process · `/contact` Contact · `*` NotFound — all inside `components/site/Layout.tsx` (fixed 72px header, footer, mobile call/WhatsApp bar).

## Key components (`frontend/src/components/site/`)
`Layout`, `SiteHeader` (sticky nav + gold active underline + mobile overlay), `SiteFooter` (navy band, NAP), `ContactBar` (mobile click-to-call + WhatsApp), `PageHeader` (photo or drafting-sheet header), `SectionHeading`, `Reveal` (IntersectionObserver reveal, reduced-motion safe), `PillarGrid`, `WhyChoose`, `ServicesLedger` (summary | full), `ProcessLedger` (compact | full), `ProjectsLedger` (filter tabs + row ledger + detail dialog), `ConsultationForm`, `CtaBand`.

## Design decisions
- Signature: blueprint/drafting-sheet ledger motif — services, projects and process are numbered hairline rows with gold index numerals, never card grids. Navy filled/solid CTA pills, gold used only for numerals, eyebrows, rules and active underlines. No shadows (hairlines carry separation).
- Extra tokens added in a separate `:root` block at the end of `index.css` (`--primary-hover`, `--rule-on-dark`, `--rule-on-light`, `--hero-scrim`, `.font-display`, `.hero-scrim`) — the locked theme block was not touched.
- Photography: real Unsplash construction/architecture images (hero, page headers, service and project thumbnails). Graded dark bottom scrim on photo headers only for text contrast.

## Deliberate content constraints (user instruction)
No invented years of experience, project counts, certifications, awards or client numbers. Stats were replaced by the four qualitative commitments (Quality Construction, Professional Project Management, Reliable Service, Client-Focused Approach). The portfolio is representative sample content, each row badged "Sample", and the footer/Our Work page state that entries are placeholders to be replaced with verified projects. No company email or postal code is published (not supplied).

## Checks run
`cd /app/project/backend && python -m pytest -q tests/test_api.py` covers health, services, projects (filter + 404), pillars, process, consultation creation/persistence and validation failures.

## Open items for the client

## Website domain (recommendation given, client decision pending)
The public link is currently the platform preview hostname, which is review-only and is served with `noindex` (see the hostname guard in `frontend/index.html`). A custom domain is attached from the platform's deployment settings — it is a DNS/registrar action, not a code change, and nothing in this codebase hardcodes a domain.

Recommended: `anchorbolt.com.gh` as primary (Ghana ccTLD — read as a locally registered business), with `anchorboltgroup.com` / `anchorboltconstruction.com` as the international fallback to register alongside it.

Code side is already domain-agnostic: `index.html` injects `rel=canonical` and `og:url` from `location.origin` at runtime, the Open Graph image is an absolute CDN URL, and `frontend/.env.production` (backend URL) is regenerated by the platform on deploy. Nothing needs editing once the domain is chosen.
